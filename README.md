# projet-Communication-Web
Projet final Groupe 3 
Objectif : L'objectif de cette première séance est de mettre en place le dépot git, la structure du projet, la base de données et la page HTML de base avec Bootstrap.

**Présentation**

Application collaborative de type forum/gestionnaire permettant :

- la création de sujets
- l’ajout de réponses
- la communication en temps réel via WebSocket.
